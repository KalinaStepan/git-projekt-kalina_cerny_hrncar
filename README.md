# DomaciUkol

                                ---------/výpočet kruhu a koule\---------

                    Popis: webová stránka na výpočet kruhu a koule. Jednoduchý prográmek 
                    který zlepší život každému  co nechce počítat na papír.

                    1)  Stáhni so složku ---> Přetáhni ji na místo ke ji chceš mít (plocha...).  
                    2)  Otevři složku a rozklikni "index.html" ---> Hodí ti tě to na Webovou 
                        stránku.
                    3)  Vypln údaje ---> pokud nemáš vymysli (jina to nebude fugovat).
                    4)  Užij si výsledek
